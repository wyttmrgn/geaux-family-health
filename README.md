# Geaux Family Health concept

A one-page website concept for Geaux Family Health, 2900 Forsythe Avenue, Monroe, LA. Their domain (geauxfamilyhealth.com) currently forwards to their Facebook page, and their Google listing has no website attached.

This is a design preview, not the clinic's live website. The page carries a `noindex` tag that comes off at launch.

## Where the details come from

| Detail | Source |
| --- | --- |
| Address, phone, hours, 4.6 rating (42 reviews) | Google Business listing |
| Email, "infancy through geriatric", 98% recommend (60 reviews) | Facebook page |
| Fax number | NPI registry listing |
| Provider names (Tiffany Terra, FNP and Angie Belanger, FNP) | WebMD, Vitals, Tebra and patient reviews |
| Review excerpts | Google reviews, shortened, first name and last initial only |
| Accessibility and payment notes | Google Business listing |

## Confirm with the clinic before launch

- The services listed under "Care for every stage of life" and "Often seen for". These are standard family practice services, not a list the clinic published.
- That both providers are accepting new patients, and how each wants her name and credentials written.
- Insurance wording. The page only says to call and check.
- Permission to quote the reviews.
